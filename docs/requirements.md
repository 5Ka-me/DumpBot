# Dump Bot — требования (зафиксировано 2026-10-06)

Личный Telegram-бот-«свалка»: принимает текст, голосовые, картинки, ссылки, пересланные посты;
ИИ (chutes.ai) разбирает сообщение на записи, создаёт задачи и напоминания, отвечает на вопросы по базе.

## Пользователи и объём
- Один пользователь (владелец). Доступ по whitelist Telegram ID (`OWNER_ID`), остальных бот игнорирует.
- До 20–30 сообщений в день; голосовые короткие (до ~10 с).
- Языки: смесь RU/EN. Интерфейс бота — русский.

## Контент
- MVP: текст, голосовые, фото (и картинки, отправленные файлом), ссылки, пересланные посты.
  Прочее (видео, кружочки, стикеры, документы, гео) — сохраняется как запись «Другое»; подпись, если есть, разбирается ИИ.
- Ссылки: просто сохранять (заголовок страницы бот подтягивает сам, без ИИ).
- Картинки: отправляются в ИИ (vision-модель): распознать текст (OCR) + категория. Поиск «по смыслу» не нужен.
- Одно сообщение → несколько записей, если в нём несколько независимых вещей.
- Пересланные посты: сохранять источник (канал/автор, ссылка).
- Приватность: в chutes уходит полное сообщение (текст, транскрипт, картинки, голос) — это ок.

## Категории
Фиксированный список (+ автоматические теги от ИИ, всё правится вручную):
Задача, Событие/напоминание, Идея, Мысль/заметка, Покупка, Ссылка/сохранёнка, Мем, Цитата, Другое.
Отдельного списка покупок не нужно.

## Время и напоминания
- Часовой пояс: `Europe/Warsaw` (с переводом часов), настраивается.
- Словарь времени суток (настраивается): утро 09:00, обед 13:00, вечер 19:00, после работы 18:30,
  «на выходных» — суббота 11:00, «завтра» без времени — 10:00.
- Напоминание по умолчанию — **за 5 минут до события** для всех событий с указанным временем;
  можно переопределить в сообщении («напомни за 30 минут»).
- Задача без времени → напоминание в 19:00 (настраивается в меню настроек бота);
  если сообщение пришло после 19:00 — завтра в 19:00. Только для задач (задача/событие/покупка), не для идей/заметок.
- «В обед», сказанное после обеда → завтра.
- Напоминание создаётся сразу, в карточке кнопки «изменить/отменить». Кнопки «Готово» в карточке создания нет
  (2026-10-06): она есть в напоминании и в меню «✏️ Изменить».
- Повторяющиеся задачи нужны: «Готово» закрывает текущее повторение, следующее создаётся само;
  остановить — кнопкой в карточке или через `/recurring`.
- Дайджесты: утренний 09:00 (задачи на сегодня + просроченные), вечерний 21:00 (сделано/не сделано +
  кнопка «перенести на завтра»). Время настраивается.
- Тихие часы (настраиваются, по умолчанию 23:00–08:00): явно заданное время («в 23:30») присылается как обычно;
  автоматические сообщения (дайджесты, задачи без времени) в тихие часы не отправляются.
- Если не нажал «Готово» — повторно не напоминать, задача попадает в вечерний итог.
- Задачи: просто сделано / не сделано.

## Доступ к данным
- MVP: команды бота (`/today`, `/tasks`, `/search` …) + вопросы обычным языком («что у меня завтра?»).
- Намерение «сохранить» vs «спросить» определяет ИИ; `?` в начале сообщения принудительно включает режим вопроса.
- Позже: Telegram Mini App, синхронизация с Notion/Obsidian.
- Редактирование: (а) ответ (reply) на карточку бота текстом — ИИ применит; (б) кнопка «✏️ Изменить» с меню полей.
  Редактирование исходного сообщения в Telegram запись **не** меняет.
- Реакция на сообщение: заметки/идеи/мемы/ссылки — только реакция-эмодзи 👌; задачи/события — карточка с кнопками.

## ИИ (chutes.ai)
- Только chutes (оплата по факту), бюджет до **$5/мес**.
- Модели подбираю сам; ID моделей в конфиге.
- Если chutes недоступен: сохранить сообщение и обработать позже (очередь с повторами) + запасная модель внутри chutes.
- Голос — распознавание через chutes и/или локальный Whisper (итерация 2: [features/iteration-2.md](features/iteration-2.md), B).
- Бюджет: предупреждение при 80%, при 100% ИИ выключается до конца месяца, сообщения сохраняются и обрабатываются позже.
- Проактивность (связи со старыми заметками, подзадачи) — потом.

## Инфраструктура
- Python, Docker Compose, long polling. Сейчас Windows-ПК, в планах — Raspberry Pi (ARM64) → образы multi-arch.
- Postgres доступен с хоста только на `127.0.0.1:5432` (для DBeaver).
- Бэкапы пока не делаем. Файлы не копируем — храним `file_id` Telegram.
- Локальный git-репозиторий; GitHub/CI — потом.

## Изменение 2026-10-07: только время уведомления
Пользователь отказался от разделения «время события» / «время напоминания». У записи есть **только время уведомления**:
- «встреча в 15» → уведомление в 15:00; «в обед» → 13:00. **Никаких «за 5 минут» по умолчанию.**
- «Напомни за 30 минут до встречи в 15» → уведомление в 14:30; время встречи остаётся в названии/описании («Встреча (15:00)»).
- «За день и за час» → несколько времён уведомления, только если пользователь явно попросил.
- Дедлайны «до пятницы» — оба уведомления остаются: накануне в 19:00 и в день дедлайна в 10:00.
- Кнопки «⏰ 15 мин / 1 час / 📅 Завтра» переносят само время записи (в `/today`, дайджестах и Mini App она тоже переезжает).
- Несработавшие уведомления «за 5 минут» у существующих записей переносятся на само время (12:55 → 13:00).
- «⏱ Напомнить за…» убирается из карточки, `/settings` и Mini App.
- Не меняются: тихие часы, повторы, периоды («на этой неделе»), «через N минут/часов», 19:00 для задач без времени.
